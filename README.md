# 🏥 中西医结合 AI 智能诊疗网站

## 部署指南

### 一、项目说明

本项目是一个**纯前端单页应用（SPA）**，使用 HTML + CSS + JavaScript 原生技术栈开发，**无需任何构建工具、服务器或数据库**，打开即可使用。

**适用场景**：个体诊所、中医馆、社区卫生服务中心的智能辅助诊疗演示/试用系统

### 三、快速开始（3步即可运行）

#### 方法一：双击直接打开（最简单）

1. 找到文件夹中的 `index.html`
2. **双击打开**
3. 系统自动在默认浏览器中启动 ✅

#### 方法二：右键选择浏览器打开

1. 右键点击 `index.html`
2. 选择「打开方式」→ **Chrome / Edge / Firefox / Safari**
3. 推荐使用 **Chrome** 或 **Edge** 浏览器以获得最佳体验

#### 方法三：本地服务器（推荐用于正式演示）

如果需要更稳定的运行环境，可以用本地服务器：

**Windows 方式：**
```powershell
# 进入项目目录
cd "桌面\中西医结合 AI 智能诊疗网站"

# Python方式（如果安装了Python）
python -m http.server 8080

# 或 Node.js方式（如果安装了Node.js）
npx serve .
```

然后在浏览器访问 `http://localhost:8080`

### 六、核心特性

✅ **零依赖部署** — 无需Node.js/Python/数据库/服务器  
✅ **全响应式设计** — 完美适配手机、平板、电脑  
✅ **AI模拟引擎** — 舌诊Canvas颜色分析、报告参考值比对、影像标注  
✅ **语音交互** — Web Speech API实现语音转文字  
✅ **数据持久化** — 浏览器LocalStorage本地存储  
✅ **合规标注** — 所有AI分析结果均标注"仅供医师参考"  
✅ **离线可用** — 除语音识别外，所有功能可离线使用

### 八、注意事项

1. **数据存储**：所有数据保存在浏览器的 LocalStorage 中
   - 清除浏览器数据会导致所有记录丢失
   - 建议定期使用「数据备份」功能导出数据
   - 不同浏览器之间的数据不互通

2. **AI分析为模拟演示**：
   - 舌诊分析基于图像颜色算法，非真实深度学习模型
   - 报告解读基于参考值规则匹配
   - 影像标注为模拟展示
   - **所有AI结果仅供学习和演示参考**

3. **语音功能**：
   - 仅支持 Chrome / Edge 浏览器
   - 需要麦克风权限
   - 部分网络环境可能不可用

4. **合规声明**：
   - 本系统**不是**医疗器械软件
   - 不能替代专业医师的诊断和治疗决策
   - 所有AI分析结果均标注「仅供参考」
   - 正式医疗场景需获得相关资质审批

### 九、常见问题

**Q: 为什么打不开或显示空白？**
A: 请确认使用 Chrome/Edge 浏览器，按 F12 打开开发者工具查看控制台是否有红色错误。尝试直接双击 index.html 打开。

**Q: 数据会丢失吗？**
A: 数据存储在浏览器 LocalStorage 中，只要不手动清除浏览器数据就不会丢失。建议定期在管理后台使用「数据备份」功能导出。

**Q: 可以多人同时使用吗？**
A: 当前版本为纯前端单机版，数据存储在各设备本地浏览器中。如需多设备同步，需要后续接入云端数据库。

**Q: 如何替换LOGO？**
A: 进入管理后台 → 系统设置 → 上传LOGO图片即可。

**Q: 手机上能正常使用吗？**
A: 可以！系统采用全响应式布局，在手机浏览器中打开即可获得原生App般的体验。可以添加到主屏幕作为PWA使用。
